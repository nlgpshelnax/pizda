# Движение в «О!дин запрос»

Существующая палитра, шрифты и композиция сохранены. Основной принцип — короткая реакция на действие и непрерывность между состояниями.

## Реализация

- `src/motion.tsx`: общие длительности, easing, настройки уменьшения движения и видимости вкладки. Подписки очищаются при размонтировании.
- `src/motion.css`: реакции кнопок и полей, выезжающая панель, уведомления и подтверждения. Без пружин, параллакса и постоянного пульсирования.
- `Workspace.tsx`: пять предложений появляются с шагом 55 мс, за 300 мс каждое. Пока агент отвечает, прежние результаты остаются видны. Обновление использует короткое перекрытие прозрачности; уходящий слой недоступен для взаимодействия и чтения скринридером.
- Перестановка при сортировке и выборе компактной поездки использует стабильные идентификаторы. Выбранная компактная поездка становится основной только в отображении; исходное ранжирование агента не изменяется. Новая сортировка снимает это закрепление. Изображение и название связаны через shared layout; анимации ограничены текущей версией результатов.
- `JourneyCard.tsx` / `Modal.tsx`: подробности открываются справа за 320 мс, на телефоне занимают весь экран. Обычные окна появляются с масштаба .97 за 220 мс и закрываются за 150 мс. Сохраняются native dialog, Escape, фокус и блокировка фоновой прокрутки.
- `Chat.tsx`: новые сообщения проявляются за 210 мс. Восстановленная история не проигрывается повторно. Плавная прокрутка следует за сообщениями только рядом с концом истории; чтение старых сообщений сохраняет позицию.
- `Toast.tsx`: одно уведомление с закрытием, различимый вариант ошибки, пауза времени показа при наведении, фокусе и скрытой вкладке. Уведомления о сохранении, настройке напоминаний и подготовке PDF возникают после выполнения действия. Успешная отмена по-прежнему показывается отдельным заметным окном.
- Слайдер сохраняет интервал 15 секунд и горизонтальный переход 750 мс. Ввод запроса, остановка на наведении/фокусе, скрытая вкладка и уменьшение движения сохранены.

Добавлена единственная зависимость: `motion` (Motion for React). Простые состояния остаются на CSS; native dialog анимируется Web Animations API. Официальная документация: https://motion.dev/docs/react-layout-animations и https://motion.dev/docs/react-animate-presence.

## Проверка

`node scripts/motion-qa.mjs` проверяет 1440, 1280, 1024 и 390 px: количество предложений, отсутствие переполнения, панель подробностей, неизменность параметров при открытии, Escape и возврат фокуса, уведомления, пересчёт, перестановку компактной поездки, отсутствие повторной анимации старых сообщений, сохранение позиции чата и динамическое включение reduced motion.

Также используются существующие `npm test`, `npm run test:e2e`, `npm run test:redesign`, `node scripts/slideshow-cancel-qa.mjs` и `npm run build`. После сброса поездки e2e ожидает фактического завершения закрытия окна, прежде чем вводить новый запрос.

Скриншоты и отчёт: `test-results/motion/`. Проверка проводится в Chromium/Edge с эмуляцией ширины телефона; физические iOS/Android устройства не проверялись. Сборщик предупреждает о размере основного файла и лениво загружаемого PDF-шрифта; сборка завершается успешно.

Точка восстановления перед началом: соседняя папка `Хакатон-motion-backup-20261028` (исходники, зависимости и сценарии проверки).
