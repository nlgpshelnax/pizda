# PDF, календарь и примеры запросов

## Формирование плана

Кнопка «Скачать план PDF» доступна после успешного демо-оформления. Источник документа — подтверждённый снимок `booking.result` и `booking.preferences`. При изменении поездки скачивание скрывается до нового оформления. Экспорт календарного события `.ics` остаётся самостоятельной функцией.

Для PDF использованы `pdf-lib` и `@pdf-lib/fontkit`: они создают векторный текст непосредственно в браузере и встраивают локальные Montserrat и Prata с кириллицей. Платные сервисы не вызываются. Данные готовятся отдельно от вёрстки и скачивания. Цена переносится из подтверждённого расчёта, а не вычисляется заново другим алгоритмом.

Страница A4 содержит логотип, направление, даты и гостей, маршрут туда и обратно, гостиницу, разбивку стоимости, занятия, ограничения и чек-лист. Демонстрационный статус явно указан. Неизвестные данные требуют уточнения; расписание относится к существующему учебному маршруту. Номера билетов и настоящих бронирований не создаются.

Вёрстка строго одностраничная. Если важные сведения не помещаются, создание файла прекращается с понятным сообщением, без обрезания содержания. PDF пока не имеет структурной разметки tagged PDF; работа с реальным экранным диктором не проверялась.

## Календарь

`DateField` сохраняет ручной ввод, показывает календарь по кнопке и Alt+↓. Стрелки перемещают фокус по дням, Home/End — по неделе, Page Up/Down — по месяцам, Shift+Page Up/Down — по годам. Escape закрывает календарь и возвращает фокус к кнопке. Даты до минимально допустимой недоступны. Выбранная дата проходит существующую проверку оформления и сохраняется в сессии.

## Основные файлы

- `src/booking/pdfData.ts` — подготовка сведений подтверждённой поездки.
- `src/booking/tripPdf.ts` — страница PDF, встроенные шрифты и загрузка.
- `src/components/Booking.tsx` — доступ к экспорту и календарю, обработка ошибок.
- `src/components/JourneyCard.tsx`, `Workspace.tsx` — удалена прежняя загрузка TXT до оформления.
- `src/components/DateField.tsx`, `date-field.css` — календарь.
- `src/components/Welcome.tsx` — примеры без скрытых условий.
- `public/fonts/*.ttf`, `LICENSE-*.txt` — шрифты для PDF и их лицензии.
- `package.json`, `package-lock.json` — зависимости PDF и типы Node.js для тестов.

## Проверки

Из папки `frontend`:

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
npm.cmd run test:redesign
node scripts/calendar-qa.mjs
node scripts/welcome-polish-qa.mjs
node scripts/pdf-qa.mjs
python scripts/check-pdf.py
```

Последняя проверка требует `pdfplumber`. Она сопоставляет содержимое реально скачанных PDF со стоимостью, датой и количеством гостей в интерфейсе и проверяет A4, одну страницу и границы символов. Примеры и изображения для просмотра сохраняются в `test-results/pdf/` и `test-results/calendar/`.
