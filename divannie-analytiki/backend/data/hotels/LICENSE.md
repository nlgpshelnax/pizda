# OpenStreetMap-derived snapshots

`osm-properties.json` and `osm-activities.json` contain data derived from OpenStreetMap.

Each record retains its OpenStreetMap object URL and retrieval time. Coverage is a limited sample of
Sochi, Kazan, Dubai and Hurghada; it is not a complete inventory or confirmation of current business
status. Coordinates of ways/relations are approximate geometry centroids, not entrances. Prices,
availability, reviews and unconfirmed policies are intentionally absent.

This notice applies to the OSM-derived data, not to unrelated project code or third-party API data.
