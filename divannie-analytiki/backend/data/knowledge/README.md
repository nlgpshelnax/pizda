# Справочник направлений

`destinations.json` — seed для explore: координаты/часовые пояса и небольшой словарь vibes. Ссылки OpenStreetMap относятся к месту на карте, а не подтверждают комфорт, сезонность или визовые условия. `seasonality_kind=curated_hypothesis`, `seasonality_verified=false`, `climatology=null`: числовая климатология и прогноз не выдуманы. Роль 5 должна проверить/обосновать сезонность и теги перед публичными продуктовыми утверждениями.

Погода из Open-Meteo передаётся отдельным forecast tool с горизонтом покрытия. Наличие POI из Overpass само по себе не доказывает «тихо», «безопасно» или «можно с собакой».
