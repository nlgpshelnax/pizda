## Проверка на машине защиты

Требуются Python 3.12 и uv; установка зависимостей из lockfile требует сети. Из корня checkout:

```bash
uv sync --frozen
uv run python scripts/load_database.py
uv run python scripts/rehearse_demo.py
uv run python scripts/check_data.py
uv run uvicorn trip_data.main:app --host 127.0.0.1 --port 8000
```

Rehearsal создаёт отдельную временную БД и принудительно отключает исходящие HTTP-запросы поставщиков. Проверяет три поездки, маркировку mock, пересборку с ребёнком, низкий бюджет, питомца без подходящей котировки, устаревшую версию и поведение weather API при сбое. Это автоматическая проверка backend-контракта; реальную интеграцию чата и UI должны прогнать владельцы ролей 1 и 3.

При желании проверить действующий сервер во втором терминале:

```bash
uv run python scripts/smoke.py
# После перезапуска сервера и с той же БД:
uv run python scripts/smoke.py --restore
```

Smoke создаёт записи тестового плана и демозаказа в локальной БД. Он использует mock context по умолчанию. Контракт API и примеры в `/docs`; дополнительная инструкция [для роли 1](role-1-ai.md), [схема БД](database-first.md).

## Источники и обновления

- `uv run python scripts/ingestion_worker.py --interval 1800` обновляет Open-Meteo, OSRM, Travelpayouts и Tutu; `--once` выполняет один запуск, `--offline` использует локальные fixtures.
- `uv run python scripts/sync_xotelo.py --interval 21600` запускается отдельно; `--city`, `--check-in`, `--check-out` и `--adults` ограничивают выборку.
- `uv run python scripts/load_database.py --refresh-hotels` вручную обновляет ограниченные районы OSM; при ошибке сохраняется прежний снимок, `osm_refresh` записывается в журнал, а команда возвращает ошибку. Не запускать чаще без согласования лимитов источника.
- Процессы обновления должны работать на машине защиты или под её менеджером сервисов; один запуск не устанавливает постоянное расписание. `check_data.py` и `/api/v1/catalog-quality` показывают просроченные данные и ошибки источников.

## Перед защитой

1. Запустите онлайн-обновление `uv run python scripts/sync_service.py --once`. Оно обновляет доступные источники в рамках поддерживаемого покрытия, а кэш может сохранить текущие ответы. Проверьте статус и `check_data.py`: предупреждение о сроке данных требует внимания; свежесть одних источников не подтверждает другие.
2. Демо должно показывать `data_mode=mock`, предупреждение `DEMO_DATA` и статус визы `unknown` или требующий проверки. Погода из БД может быть пустой и покрывает только реально загруженные дни; не выводите её как прогноз на весь срок.
3. Агент использует `/api/v1/catalog/context`, `/api/v1/tours/search` и `/api/v1/plans`. При изменении плана передаёт текущую `base_version`, учитывает 409 и возвращённую новую версию. Сквозную репетицию с чатом ещё требуется выполнить.
4. UI берёт стоимость из `search.options[].total`, ограничения из `issues` и `limitations`, причину отсутствия вариантов из `rejected`; pending-услуга и demo order не являются подтверждённым бронированием.

Xotelo поставляет ориентировочные цены, которые не подтверждают бронь. LiteAPI не используется в выбранном демосценарии. Живые тарифы ЖД/трансфера и источник визовых правил отсутствуют. Эти пункты требуют доступа к подходящим поставщикам и не закрываются запуском демосценариев.

## Результат прогона 27 октября 2026

В облачной среде выполнены `ruff check .`, `pytest -q` (85 тестов), `run_data_evals.py` (30/30), `rehearse_demo.py`, HTTP `smoke.py` и `smoke.py --restore` после фактического перезапуска сервера. Экспорт проверен на внешние ключи и отсутствие таблиц планов, заказов и запросов услуг. Это backend-проверки; совместный прогон с реальным агентом и UI ещё не выполнялся.

Online worker обновил доступные данные, включая 20 расписаний Москва → Казань и 13 обратно. При повторной загрузке Xotelo для Дубая два отеля вернули оценки, один — timeout; статус partial сохранён. Проверка качества показала истёкшие исторические записи погоды/авиаоценок и отсутствие подтверждённых тарифов отелей. Актуальные API-выборки исключают записи с истёкшим TTL. Перед защитой прогоните команды заново на машине команды.
