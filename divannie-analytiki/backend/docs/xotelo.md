# Отели: источник Xotelo

Основной бесплатный вариант для исследования отельных цен — [Xotelo](https://xotelo.com/). На 27 октября 2026 без ключа отвечают `/list` и `/rates`; поиск `/search` вернул сообщение о необходимости RapidAPI. Карта не добавлялась. Поставщик указывает, что источником выступают данные TripAdvisor. Условия повторного использования, актуальность, лимиты и допустимость коммерческого применения необходимо уточнить у поставщика до production.

Список доступных четырёх городов задан в `providers/xotelo.py` через подтверждённые location ID. Загружаем до трёх объектов на город и предложения на одну комнату, двух взрослых и конкретные даты. Это небольшой набор для демонстрации, не полный каталог и не поиск по произвольным городам. Данные из Xotelo хранятся отдельно от OSM: не сопоставляйте объекты по названию без дополнительной проверки.

```bash
# Разовая загрузка, даты можно заменить:
uv run python scripts/sync_xotelo.py --check-in 2026-11-10 --check-out 2026-11-15
# Периодически каждые 6 часов, Ctrl+C для остановки:
uv run python scripts/sync_xotelo.py --interval 21600
```

Без дат выбирается период через 21 день на пять ночей; при периодическом запуске он пересчитывается. Источник может возвращать пустые результаты, HTTP-ошибки или таймауты: ошибки по городу фиксируются в `ingest_runs` и выводятся в stdout; блокировка не даёт запустить две загрузки Xotelo одновременно; скрипт при частичной ошибке имеет код выхода 1 (в режиме цикла продолжает работу). Метаданные сохраняются, старые записи не затираются. Для защиты от устаревших результатов ставки доступны через API только в течение шести часов после timestamp источника; успешный пустой ответ инвалидирует предыдущую ставку на тот же scope.

`GET /api/v1/hotels/estimates?city=Дубай&check_in=2026-11-10&check_out=2026-11-15&adults=2` читает только БД и возвращает цену `nightly_minor` в копейках **за комнату за ночь**, даты, число взрослых, продавца, время источника и срок действия. Последнее состояние загрузки отображается в `last_sync`; частичная ошибка обозначается предупреждением. Даты задаются парой; при поиске для конкретной поездки передавайте даты и число взрослых. Загружаемые оценки относятся к одному номеру и гостям без детей. Налоги и полная цена не подтверждены; pets и breakfast не определены. Источник может содержать несколько продавцов одного отеля. Каждая запись `bookable=0`, поэтому её нельзя выдавать за подтверждённую цену или вставлять в полный тур. При ошибке источника старые оценки до конца TTL остаются видимыми; после TTL не возвращаются.

На первой проверке 27 октября 2026 загрузились карточки 3 отелей в каждом городе и 16 оценок для части объектов Дубая и Хургады на 10–15 ноября. Все три запроса тарифов в Сочи и Казани истекли по таймауту; покрытие не гарантируется. Значения и доступность меняются. Чтобы получить более полную выдачу, нужны лимиты источника, а для полного тура — поставщик подтверждённых отельных, транспортных и трансферных тарифов. Mock-бандлы для демо сохранены и помечены.

LiteAPI более не является рекомендуемым источником для этого проекта; старые интеграционные endpoints оставлены для совместимости. Для Xotelo ключи не требуются. Общая БД экспортируется с новыми таблицами через `scripts/export_database.py`; на других машинах данные создаются повторным запуском загрузчика либо переносом выгрузки.
